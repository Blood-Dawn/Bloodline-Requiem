🎮 GAME FLOW THROUGH FILES
═══════════════════════════════════════════════════════════════

1. startup.txt
    → Initializes game
    → Routes to origin_select.txt

2. origins/origin_select.txt
    → Player chooses origin
    → Routes to origin_*.txt

3. origins/origin_*.txt
    → Sets initial stats
    → Routes to appropriate act1_*.txt
    → (Legacy prologue.txt still exists; refactor into origin_assassin.txt)

5. act1_*.txt
    → Main Act 1 content
    → Should call rank_progression.txt for XP
    → Routes to act2_common_hub.txt

6. rank_progression.txt
    → Grants XP when called
    → Checks for rank-up
    → Calls ability selection if rank-up earned

7. systems/*_abilities.txt
    → Player chooses 2 abilities
    → Sets boolean flags
    → Returns to calling scene

8. Act scenes check ability flags
    → Example: *if (shadow_step)
    → Offer special choices
    → Enhanced gameplay
